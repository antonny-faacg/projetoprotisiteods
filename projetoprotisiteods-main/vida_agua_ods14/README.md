# Vida+Água — ODS 14

Site simples e responsivo inspirado no ODS 14 da ONU — Vida na Água.

## Páginas
- index.html — Início
- ods14.html — ODS 14
- especies.html — Espécies
- problemas.html — Problemas

- metas.html — Metas
- sobre.html — Sobre

## Tecnologias
Somente HTML5 e CSS3. Não usa JavaScript.

O formulário utiliza validação nativa do HTML. Sem backend, os dados não ficam salvos permanentemente.
